# Brew & Bloom — Botanical Coffee Sanctuary
An artisanal cafe web platform celebrating single-origin craft roasts, botanical calm, and mindful living rituals.

Built entirely with clean,  HTML and  CSS with zero JavaScript dependencies.

Structured modularly across Home, Menu & Media, Coffee Club Registration, Services, Portfolio, and Contact pages.

Crafted using CSS Grid and Flexbox layouts, fluid Google Fonts typography (Playfair Display & DM Sans), and keyframe animations.


Highlights include an interactive media showcase, curated artisanal price table, and an accessible multi-field membership form.

Optimized for mobile-first responsiveness, semantic accessibility standards, and fast native browser performance.
